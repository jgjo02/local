# Week 6: ETF 추천 RAG 시스템 구현

## 주요 학습 내용

금융 상품(ETF) 추천을 위한 RAG 시스템을 설계하고 구현합니다.

## 세션 구성

| 차시 | 주제 |
|------|------|
| 1차시 | 추천 시스템 & ETF 데이터 수집/전처리 |
| 2차시 | 평가 데이터셋 합성 |
| 3차시 | ETF 상품 검색 구현 |
| 4차시 | 투자 성향 기반 추천 로직 |
| 5차시 | Gradio UI & HuggingFace Space 배포 |

## 학습 목표

- 금융 도메인 RAG 시스템 설계 및 구현
- 합성 데이터셋으로 평가 파이프라인 구축
- 하이브리드 검색 + 재순위화 적용
- HuggingFace Space에 배포

## 핵심 컴포넌트

```
[데이터 수집] → [ETF 임베딩] → [하이브리드 검색]
                                        ↓
[투자자 프로파일] → [RAG 추천 체인] → [Gradio UI]
```
