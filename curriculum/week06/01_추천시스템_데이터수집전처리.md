## 1. ETF란?

```
ETF (Exchange-Traded Fund): 거래소에서 주식처럼 거래되는 펀드

종류:
  주식형:  KODEX 200 (KOSPI 200 추종)
  채권형:  TIGER 국채3년
  원자재:  KODEX 골드선물
  해외:    TIGER 미국S&P500
  레버리지: KODEX 레버리지 (2배 추종)
  인버스:  KODEX 인버스 (반대 방향 추종)
  테마:    KODEX 반도체, TIGER 2차전지
```

## 2. 금융 데이터 수집

```python
# yfinance 활용
import yfinance as yf

def get_etf_info(ticker: str):
    """ETF 기본 정보 수집"""
    etf = yf.Ticker(ticker)
    info = etf.info
    history = etf.history(period="1y")

    returns = {
        "1m": calculate_return(history, 30),
        "3m": calculate_return(history, 90),
        "6m": calculate_return(history, 180),
        "1y": calculate_return(history, 252),
    }
    return {
        "ticker": ticker,
        "name": info.get("longName", ticker),
        "expense_ratio": info.get("annualReportExpenseRatio", 0),
        "aum": info.get("totalAssets", 0),
        "returns": returns
    }
```

## 3. ETF 텍스트 데이터 구성 (RAG용)

```python
def build_etf_text(etf_data: dict) -> str:
    """ETF를 RAG 검색용 텍스트로 변환"""
    return f"""
ETF명: {etf_data['name']} ({etf_data['ticker']})
카테고리: {etf_data['category']}
운용 자산: {etf_data['aum']:,}억원
수수료율: {etf_data['expense_ratio']:.2f}%
위험 등급: {etf_data['risk_level']}

수익률 정보:
  1개월: {etf_data.get('1m_return', 0):.1f}%
  3개월: {etf_data.get('3m_return', 0):.1f}%
  1년: {etf_data.get('1y_return', 0):.1f}%

특징: {etf_data.get('description', '')}
투자 테마: {', '.join(etf_data.get('theme', []))}
"""
```

## 💡 핵심 포인트
- ETF 데이터는 수치(수익률, 수수료)와 텍스트(설명, 테마)를 통합 처리
- RAG용 텍스트는 검색에 유리하게 구조화된 형식으로 작성
- 실시간 데이터 수집 시 API 호출 제한 고려
