## 1. ETF 텍스트 표현 설계

### 1.1 효과적인 텍스트 빌딩

ETF를 검색 가능한 텍스트로 변환하는 것이 RAG 품질의 핵심입니다.

```python
def build_etf_text(etf: dict) -> str:
    """ETF 정보를 검색 최적화 텍스트로 변환"""
    text = f"""ETF명: {etf['name']} (티커: {etf['ticker']})
카테고리: {etf['category']} | 투자지역: {etf['region']}
위험등급: {etf['risk_level']} | 운용보수: {etf['expense_ratio']}%
운용규모: {etf['aum_billion']:,}억원

수익률: 1개월 {etf['1m_return']:+.1f}%, 1년 {etf['1y_return']:+.1f}%, 3년 {etf['3y_return']:+.1f}%

설명: {etf['description']}
투자 테마: {', '.join(etf['theme'])}"""
    return text
```

**텍스트 설계 원칙**:
- 정형 데이터(수치)와 비정형 데이터(설명) 결합
- 검색 키워드(카테고리, 테마)를 명시적으로 포함
- 일관된 포맷으로 파싱 용이성 확보

### 1.2 Document 메타데이터 활용

```python
from langchain.schema import Document

doc = Document(
    page_content=build_etf_text(etf),
    metadata={
        "ticker": etf["ticker"],
        "name": etf["name"],
        "category": etf["category"],
        "risk_level": etf["risk_level"],
        "expense_ratio": etf["expense_ratio"],
        "1y_return": etf["1y_return"],
    }
)
```

메타데이터로 후처리 필터링이 가능합니다.

## 2. FAISS 벡터 인덱스 구축

### 2.1 OpenAI Embeddings + FAISS

```python
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

# 문서 목록에서 FAISS 인덱스 생성
faiss_store = FAISS.from_documents(documents, embeddings)

# 저장 및 로드
faiss_store.save_local("vector_store/etf_faiss")
loaded_store = FAISS.load_local(
    "vector_store/etf_faiss",
    embeddings,
    allow_dangerous_deserialization=True
)
```

### 2.2 검색 유형 비교

| 검색 유형 | 메서드 | 특징 |
|-----------|--------|------|
| 유사도 검색 | `similarity_search(query, k=5)` | 코사인 유사도 |
| 점수 포함 검색 | `similarity_search_with_score(query)` | (doc, score) 반환 |
| MMR 검색 | `max_marginal_relevance_search()` | 다양성 확보 |

```python
# 유사도 점수와 함께 검색
results = faiss_store.similarity_search_with_score("안전한 채권 ETF", k=5)
for doc, score in results:
    print(f"[{score:.3f}] {doc.metadata['name']}")
```

## 3. BM25 키워드 검색

### 3.1 BM25 기본 개념

BM25(Best Match 25)는 TF-IDF를 개선한 키워드 검색 알고리즘입니다.

$$\text{BM25}(q, d) = \sum_{t \in q} IDF(t) \cdot \frac{TF(t,d) \cdot (k_1+1)}{TF(t,d) + k_1 \cdot (1 - b + b \cdot \frac{|d|}{avgdl})}$$

- **k1**: 단어 빈도 포화 파라미터 (보통 1.2~2.0)
- **b**: 문서 길이 정규화 (보통 0.75)

```python
from langchain_community.retrievers import BM25Retriever

bm25 = BM25Retriever.from_documents(documents)
bm25.k = 10  # 상위 10개 반환

results = bm25.invoke("반도체 고위험 ETF")
for doc in results:
    print(doc.metadata['name'])
```

## 4. 하이브리드 검색 (Ensemble Retriever)

### 4.1 EnsembleRetriever 구현

```python
from langchain.retrievers import EnsembleRetriever

# BM25 + FAISS 앙상블
ensemble = EnsembleRetriever(
    retrievers=[bm25_retriever, faiss_retriever],
    weights=[0.4, 0.6]  # BM25 40%, Dense 60%
)

# 하이브리드 검색 실행
results = ensemble.invoke("저위험 채권형 ETF 추천")
```

### 4.2 RRF (Reciprocal Rank Fusion) 메커니즘

EnsembleRetriever는 내부적으로 RRF를 사용하여 결과를 병합합니다:

$$\text{RRF}(d) = \sum_{r \in R} \frac{1}{k + \text{rank}_r(d)}$$

- k = 60 (기본값, 높은 순위의 영향력 완화)
- 여러 검색기의 결과를 통합하여 최종 순위 결정

### 4.3 가중치 최적화

| BM25 비중 | Dense 비중 | 적합한 상황 |
|-----------|------------|-------------|
| 0.6 | 0.4 | 정확한 키워드 매칭 중요 |
| 0.4 | 0.6 | 의미 기반 검색 중요 (기본값) |
| 0.3 | 0.7 | 짧은 쿼리, 의미 파악 필요 |
| 0.5 | 0.5 | 균형 잡힌 검색 |

## 5. 메타데이터 필터링

```python
def risk_filtered_search(query: str, risk_levels: list, k: int = 5):
    """위험등급 필터링이 적용된 검색"""
    all_results = ensemble.invoke(query)
    filtered = [
        doc for doc in all_results
        if doc.metadata.get("risk_level") in risk_levels
    ]
    return filtered[:k]

# 사용 예시
safe_etfs = risk_filtered_search(
    "안전한 투자",
    risk_levels=["저위험", "중립"]
)
```

## 6. 실습: ETF 검색 시스템 구축

```python
import json
from langchain.schema import Document
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS
from langchain_community.retrievers import BM25Retriever
from langchain.retrievers import EnsembleRetriever

# 1. 데이터 로드
with open("data/sample_etf_data.json") as f:
    etf_data = json.load(f)["etfs"]

# 2. Document 생성
documents = []
for etf in etf_data:
    text = f"{etf['name']} {etf['category']} {etf['description']} {' '.join(etf['theme'])}"
    doc = Document(page_content=text, metadata=etf)
    documents.append(doc)

# 3. 벡터 스토어 구축
embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
faiss_store = FAISS.from_documents(documents, embeddings)
faiss_retriever = faiss_store.as_retriever(search_kwargs={"k": 10})

# 4. BM25 구축
bm25 = BM25Retriever.from_documents(documents)
bm25.k = 10

# 5. 앙상블 검색기
ensemble = EnsembleRetriever(
    retrievers=[bm25, faiss_retriever],
    weights=[0.4, 0.6]
)

# 6. 검색 테스트
queries = [
    "AI 반도체 고성장 ETF",
    "안전한 노후 대비 ETF",
    "미국 기술주 투자",
]
for q in queries:
    results = ensemble.invoke(q)
    print(f"\n🔍 '{q}' 검색 결과:")
    for doc in results[:3]:
        print(f"  - {doc.metadata['name']} ({doc.metadata['risk_level']})")
```
