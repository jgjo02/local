## 1. 프롬프트 엔지니어링이란?

LLM의 출력 품질을 극대화하기 위해 입력 텍스트(프롬프트)를 체계적으로 설계하는 기술

```
나쁜 프롬프트: "설명해줘"
좋은 프롬프트: "파이썬 데코레이터를 초보자에게 설명해줘.
               정의, 기본 문법, 실제 사용 예시 3개를 포함하고
               코드 블록을 사용해줘."
```

## 2. 효과적인 프롬프트 작성 원칙

### 원칙 1: 명확한 역할 부여 (Role)
```python
system = """당신은 10년 경력의 파이썬 개발자이자 교육 전문가입니다.
기술적으로 정확하면서도 초보자도 이해할 수 있게 설명하세요."""
```

### 원칙 2: 구체적 지시 (Specificity)
```
✗ "요약해줘"
✓ "3문장 이내로 핵심만 요약해줘. 전문 용어는 괄호에 설명 추가."
```

### 원칙 3: 출력 형식 지정 (Format)
```python
prompt = """다음 내용을 분석하여 JSON 형식으로 반환하세요:
{
  "요약": "2문장 이내",
  "핵심_키워드": ["키워드1", "키워드2", "키워드3"],
  "난이도": "초급/중급/고급",
  "추천_대상": "한 문장"
}"""
```

### 원칙 4: 예시 제공 (Examples)
```python
prompt = """다음 텍스트의 감성을 분류하세요.

예시:
- "정말 훌륭해요" → 긍정
- "너무 실망스럽네요" → 부정
- "그냥 평범해요" → 중립

분류할 텍스트: {text}
결과:"""
```

## 3. LangChain 프롬프트 템플릿

### 3.1 ChatPromptTemplate

```python
from langchain_core.prompts import ChatPromptTemplate

# 기본 템플릿
template = ChatPromptTemplate.from_messages([
    ("system", "당신은 {domain} 전문가입니다. 답변은 {language}로 하세요."),
    ("human", "{question}")
])

# 변수 확인
print(template.input_variables)  # ['domain', 'language', 'question']
```

### 3.2 FewShotChatMessagePromptTemplate

```python
from langchain_core.prompts import FewShotChatMessagePromptTemplate

examples = [
    {"input": "좋아요", "output": "긍정"},
    {"input": "별로예요", "output": "부정"},
    {"input": "보통이에요", "output": "중립"},
]

few_shot_prompt = FewShotChatMessagePromptTemplate(
    examples=examples,
    example_prompt=ChatPromptTemplate.from_messages([
        ("human", "{input}"),
        ("ai", "{output}")
    ])
)

final_prompt = ChatPromptTemplate.from_messages([
    ("system", "감성 분류기입니다."),
    few_shot_prompt,
    ("human", "{text}")
])
```

### 3.3 프롬프트 조합 및 변수

```python
# partial_variables로 일부 변수 미리 채우기
template = ChatPromptTemplate.from_template(
    "{role}로서 {question}에 답하세요. 답변 언어: {language}"
)

korean_template = template.partial(language="한국어")
result = korean_template.invoke({"role": "교사", "question": "AI란?"})
```

## 4. 나쁜 vs 좋은 프롬프트 예시 10쌍

| 나쁜 프롬프트 | 좋은 프롬프트 |
|-------------|-------------|
| "파이썬 코드 짜줘" | "파이썬으로 두 정수의 최대공약수를 구하는 함수를 작성해줘. 유클리드 알고리즘을 사용하고 docstring 포함" |
| "이거 번역해" | "다음 텍스트를 영어 → 한국어로 번역해줘. 전문 용어는 원문을 괄호에 유지" |
| "요약해줘" | "3개 핵심 포인트로 불릿 형식 요약. 각 포인트는 1문장" |
| "잘못 찾아줘" | "다음 코드에서 버그를 찾아 수정하고 왜 틀렸는지 설명해줘" |
| "좋은 이름 알려줘" | "파이썬 웹 크롤링 라이브러리 패키지명을 5개 제안해줘. snake_case, 8자 이내, 의미 설명 포함" |

## 💡 핵심 포인트
- 역할(Role) + 작업(Task) + 형식(Format) + 예시(Example)의 조합이 최고의 프롬프트
- `ChatPromptTemplate`은 변수를 `{variable}` 형식으로 삽입
- `partial`로 자주 쓰는 변수를 미리 채워 재사용성 향상

## ⚠️ 주의사항
- 프롬프트가 길수록 좋은 것은 아님 - 핵심만 명확히
- LangChain Hub에서 검증된 프롬프트를 활용하는 것도 좋은 전략
