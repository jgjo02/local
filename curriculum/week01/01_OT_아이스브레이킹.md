## 1️⃣ 강의 소개 및 커리큘럼 전체 개요

### 1.1 이 강의가 다루는 것

**AI 서비스 개발**은 단순히 AI 모델을 사용하는 것이 아닙니다. 실제 사용자에게 가치를 전달하는 **서비스**를 만드는 것입니다.

```
전통적인 소프트웨어 개발         AI 서비스 개발
━━━━━━━━━━━━━━━━━━━         ━━━━━━━━━━━━━━━━━
명확한 로직 코딩          →    확률적 응답 처리
정해진 출력              →    자연어 출력 파싱
단순 API 호출            →    LLM 오케스트레이션
정적 데이터베이스          →    동적 벡터 검색
규칙 기반 로직            →    프롬프트 엔지니어링
```

### 1.2 전체 커리큘럼 구조 (12주)

```
┌─────────────────────────────────────────────────────────────────┐
│                    AI 서비스 개발 12주 로드맵                      │
├──────────┬──────────────────────────────────────────────────────┤
│  1-3주차  │  기초 (Foundation)                                    │
│          │  LangChain 기초 → 문서처리 → 프롬프트 엔지니어링         │
├──────────┼──────────────────────────────────────────────────────┤
│  4-6주차  │  심화 (Advanced)                                      │
│          │  Advanced RAG → Agent → 평가 및 최적화                  │
├──────────┼──────────────────────────────────────────────────────┤
│  7-9주차  │  프로젝트 (Project)                                    │
│          │  상담 챗봇 고도화 → 멀티모달 → 프로덕션 배포               │
├──────────┼──────────────────────────────────────────────────────┤
│ 10-12주차 │  전문화 (Specialization)                               │
│          │  Fine-tuning → 보안/윤리 → 최종 프로젝트                 │
└──────────┴──────────────────────────────────────────────────────┘
```

### 1.3 학습 철학

이 강의는 **"빌드 퍼스트(Build First)"** 접근법을 따릅니다:
- 먼저 동작하는 코드를 만들고
- 그 다음 이론을 심화 이해하며
- 최종적으로 프로덕션 수준으로 개선합니다

## 2️⃣ AI 서비스 개발 트렌드 2024-2025

### 2.1 LLM 생태계의 폭발적 성장

2023년 ChatGPT 이후, AI 서비스 개발 패러다임이 근본적으로 바뀌었습니다.

```
2022년 이전               2023년               2024-2025년
━━━━━━━━━━━━━━           ━━━━━━━━━━           ━━━━━━━━━━━━━━━━
ML 전문가만 가능    →    ChatGPT 등장    →    일반 개발자도 AI 서비스 개발 가능
수개월 개발 기간    →    API 시대 개막    →    수일 만에 MVP 개발
대형 팀 필요        →    1인 스타트업    →    LLM + 프레임워크 = 생산성 혁명
```

### 2.2 주요 트렌드

#### 🔥 트렌드 1: RAG (Retrieval Augmented Generation)의 대중화
- 기업 문서를 AI에게 알려주는 가장 실용적인 방법
- Fine-tuning 대비 저비용, 빠른 업데이트 가능
- **활용 사례**: 사내 지식베이스 챗봇, 법률 문서 검색, 의료 정보 시스템

#### 🔥 트렌드 2: LLM 오케스트레이션 프레임워크
- **LangChain**: 가장 많이 사용, 생태계 풍부
- **LlamaIndex**: 문서 처리 특화
- **AutoGen**: 멀티 에이전트 특화
- **CrewAI**: 역할 기반 에이전트 팀

#### 🔥 트렌드 3: 멀티모달 AI
- GPT-4o, Gemini Ultra, Claude 3.5: 텍스트 + 이미지 + 음성
- 실제 서비스에서 텍스트만으로는 부족한 케이스 급증

#### 🔥 트렌드 4: AI Agent의 부상
- 단순 Q&A → 자율적으로 도구를 사용하는 에이전트
- 웹 검색, 코드 실행, API 호출 등을 스스로 결정
- **실제 사례**: AutoGPT, Devin (AI 소프트웨어 엔지니어)

#### 🔥 트렌드 5: 소형 모델의 약진
- Meta Llama 3, Microsoft Phi-3, Google Gemma
- 로컬 실행 가능 → 비용 절감, 개인정보 보호
- **Ollama**: 로컬 LLM 실행 도구 표준화

## 💡 핵심 포인트

> **이 강의의 핵심 메시지**: AI 서비스 개발은 "AI를 아는 것"이 아니라 "AI로 가치를 만드는 것"입니다.

1. **LLM은 도구**: ChatGPT가 대단한 것이 아니라, ChatGPT로 무엇을 만들지가 중요합니다
2. **RAG가 핵심**: 90%의 기업 AI 서비스는 RAG 패턴을 사용합니다
3. **프롬프트가 코드**: 프롬프트를 작성하는 것도 엄연한 소프트웨어 엔지니어링입니다
4. **실용성 우선**: 완벽한 이론보다 동작하는 서비스가 먼저입니다
