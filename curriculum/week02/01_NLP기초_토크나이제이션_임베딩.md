## 2. 토크나이제이션

### 2.1 토크나이제이션 방법 비교

```
방법            예시 (입력: "unbelievable")     특징
─────────────────────────────────────────────────────
단어 단위:      ["unbelievable"]                미등록어 문제
문자 단위:      ["u","n","b","e",...]            시퀀스 너무 길어짐
서브워드(BPE):  ["un", "believ", "able"]        균형잡힌 방식 ✓
```

### 2.2 BPE (Byte Pair Encoding) 알고리즘

```
학습 과정:
1. 초기: 모든 문자를 별도 토큰으로 시작
   corpus: {"l o w": 5, "l o w e r": 2, "n e w e s t": 6, "w i d e s t": 3}

2. 가장 자주 등장하는 쌍 병합
   ("e", "s") → "es" (등장 횟수: 9)

3. 다시 가장 자주 등장하는 쌍 병합
   ("es", "t") → "est" (등장 횟수: 9)

4. 반복... (사전 크기 목표에 도달할 때까지)
   최종: ["low", "lower", "newest", "widest"]

GPT-4 기준: ~100K 토큰 vocabulary
```

### 2.3 tiktoken 활용

```python
import tiktoken

enc = tiktoken.encoding_for_model("gpt-4o-mini")

text = "안녕하세요! LangChain을 배워봅시다."
tokens = enc.encode(text)
print(f"토큰 수: {len(tokens)}")
print(f"토큰 ID: {tokens}")
print(f"복원: {enc.decode(tokens)}")
```

## 3. 단어 표현 방법

### 3.1 One-Hot Encoding

```
단어 사전: {"사과": 0, "바나나": 1, "딸기": 2, "포도": 3}

사과   = [1, 0, 0, 0]
바나나 = [0, 1, 0, 0]
딸기   = [0, 0, 1, 0]

문제점:
- 차원이 어휘 크기와 동일 (수십만 차원)
- 유사한 단어 간 관계 없음 (고양이 ≠ 개, 수학적으로)
- 희소(sparse) 표현
```

### 3.2 Bag of Words (BoW)

```
문서1: "나는 사과를 먹는다"
문서2: "나는 바나나를 먹는다"

어휘: {나는:0, 사과:1, 바나나:2, 먹는다:3}

문서1 벡터: [1, 1, 0, 1]
문서2 벡터: [1, 0, 1, 1]

문제: 단어 순서 무시, 의미 표현 부족
```

### 3.3 TF-IDF

```
TF (Term Frequency): 문서 내 단어 빈도
  TF(t, d) = (단어 t가 문서 d에 등장하는 횟수) / (문서 d의 총 단어 수)

IDF (Inverse Document Frequency): 단어의 특별함
  IDF(t) = log(총 문서 수 / 단어 t를 포함한 문서 수)

TF-IDF(t, d) = TF(t, d) × IDF(t)

예시:
문서 10개, "파이썬"이 3개 문서에 등장, 특정 문서에서 5회 등장
  TF = 5/100 = 0.05
  IDF = log(10/3) = 0.52
  TF-IDF = 0.05 × 0.52 = 0.026

"은/는/이/가" 같은 조사는 모든 문서에 등장 → IDF ≈ 0 → TF-IDF ≈ 0
```

### 3.4 Word2Vec (신경망 임베딩)

```
핵심 아이디어: 비슷한 맥락에서 등장하는 단어는 비슷한 의미

Skip-gram 방식:
  입력: "먹다"
  목표: 주변 단어 ("사과", "바나나", "사람")를 예측

CBOW 방식:
  입력: 주변 단어들
  목표: 중심 단어 예측

결과: 300차원 밀집 벡터
  "왕" - "남자" + "여자" ≈ "여왕"  (벡터 연산 가능!)
```

### 3.5 코사인 유사도

```
코사인 유사도 = A·B / (|A| × |B|)

범위: -1 (완전 반대) ~ 0 (무관) ~ 1 (완전 동일)

예시:
벡터 A = [1, 2, 3]  ("사과")
벡터 B = [1, 2, 4]  ("배")
벡터 C = [5, 1, 0]  ("자동차")

A와 B의 유사도: 0.99 (과일끼리 비슷)
A와 C의 유사도: 0.31 (다른 범주)
```

## 💡 핵심 포인트
- BPE 토크나이제이션은 자주 등장하는 문자 쌍을 반복 병합하여 어휘 구성
- TF-IDF는 단어의 문서 내 중요도와 문서 간 희귀도를 결합
- Word2Vec은 단어를 밀집 벡터로 표현하여 의미적 관계 포착
- 코사인 유사도는 벡터의 방향 유사성을 측정 (크기 무관)

## ⚠️ 주의사항
- TF-IDF는 의미적 유사도를 포착하지 못함 (동의어 처리 불가)
- 한국어 형태소 분석 없이 공백 기준으로 분리하면 성능 저하
