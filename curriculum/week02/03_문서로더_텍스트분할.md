## 학습 목표

## 1. LangChain Document 객체

```python
from langchain_core.documents import Document

# Document = page_content + metadata
doc = Document(
    page_content="실제 텍스트 내용",
    metadata={
        "source": "파일경로 또는 URL",
        "page": 0
    }
)

print(doc.page_content)  # 텍스트
print(doc.metadata)      # 메타데이터
```

## 2. 주요 문서 로더

### 2.1 텍스트 파일

```python
from langchain_community.document_loaders import TextLoader

loader = TextLoader(
    file_path="data/sample.txt",
    encoding="utf-8"
)
docs = loader.load()  # List[Document]
```

### 2.2 PDF 로더

```python
from langchain_community.document_loaders import PyPDFLoader

loader = PyPDFLoader("data/report.pdf")
pages = loader.load()  # 페이지별 Document

# 페이지 범위 지정
pages_3_to_5 = loader.load()[2:5]
```

### 2.3 CSV 로더

```python
from langchain_community.document_loaders import CSVLoader

loader = CSVLoader(
    file_path="data/faq.csv",
    source_column="source",  # 소스로 사용할 컬럼
    csv_args={"delimiter": ","}
)
docs = loader.load()
```

### 2.4 웹 페이지 로더

```python
from langchain_community.document_loaders import WebBaseLoader
import bs4

loader = WebBaseLoader(
    web_paths=["https://example.com/article"],
    bs_kwargs=dict(
        parse_only=bs4.SoupStrainer(
            class_=("post-content", "post-title")
        )
    )
)
docs = loader.load()
```

### 2.5 DirectoryLoader - 폴더 내 파일 일괄 로드

```python
from langchain_community.document_loaders import DirectoryLoader

loader = DirectoryLoader(
    path="data/documents/",
    glob="**/*.pdf",           # PDF 파일만
    loader_cls=PyPDFLoader,
    show_progress=True,
    use_multithreading=True    # 병렬 처리
)
docs = loader.load()
print(f"로드된 문서 수: {len(docs)}")
```

## 3. 텍스트 분할 전략

### 3.1 청크 전략 비교

```
전략 1: 고정 크기 분할
  ┌────────────┬────────────┬────────────┐
  │  Chunk 1   │  Chunk 2   │  Chunk 3   │
  │  1000자    │  1000자    │  1000자    │
  └────────────┴────────────┴────────────┘
  장점: 구현 간단
  단점: 문장/문단 중간에 잘릴 수 있음

전략 2: 재귀적 분할 (RecursiveCharacterTextSplitter) ← 추천
  구분자 우선순위: ["\n\n", "\n", " ", ""]
  → 단락 > 줄 > 단어 > 문자 순으로 시도
  장점: 의미 단위로 분할 가능성 높음

전략 3: 문서 구조 기반
  HTML: HTMLHeaderTextSplitter (헤더 기준)
  MD:   MarkdownHeaderTextSplitter
  Code: Language.PYTHON, Language.JS

전략 4: 의미 기반 (SemanticChunker) ← 고성능
  임베딩 유사도 기반으로 의미적 경계 탐지
  단점: 느림, 비용 높음
```

### 3.2 RecursiveCharacterTextSplitter 상세

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,           # 청크 최대 크기 (문자 기준)
    chunk_overlap=200,         # 청크 간 겹침 (맥락 유지)
    length_function=len,       # 크기 측정 함수
    separators=[               # 분리자 우선순위
        "\n\n",    # 단락
        "\n",      # 줄바꿈
        ".",       # 문장 끝
        " ",       # 공백
        ""         # 문자 단위 (마지막 수단)
    ]
)

docs = splitter.split_documents(raw_docs)
print(f"청크 수: {len(docs)}")
print(f"평균 청크 크기: {sum(len(d.page_content) for d in docs) / len(docs):.0f}자")
```

### 3.3 overlap의 중요성

```
청크 1: "...계약은 쌍방의 합의에 의해 성립된다. 계약의 효력은 서명일로부터 발생하"
청크 2: "생하며, 계약 기간은 1년으로 한다. 계약 만료 30일 전까지..."

overlap 없이 검색하면:
  "서명일로부터 효력 발생 기간은?" → 청크 경계에 걸쳐 정보가 나뉨 → 검색 실패

overlap 200자로 설정하면:
  청크 1과 청크 2 모두 해당 정보 포함 → 검색 성공
```

### 3.5 한국어 텍스트 분할 최적화

```python
# 한국어 특화 구분자 설정
korean_splitter = RecursiveCharacterTextSplitter(
    chunk_size=800,
    chunk_overlap=150,
    separators=[
        "\n\n",      # 단락
        "\n",        # 줄바꿈
        "。",        # 일본어/중국어 마침표 (혼용 문서)
        ".",         # 영문 마침표
        "! ",        # 느낌표
        "? ",        # 물음표
        " ",         # 공백
        ""
    ]
)

# 주의: 한국어는 공백 없이 이어지는 경우 많음
# → chunk_size를 문자 기준으로 설정할 때 영어보다 작게 설정 권장
```

## 4. 청크 품질 평가

```python
def analyze_chunks(docs: list, sample_size: int = 5):
    """청크 품질 분석"""
    sizes = [len(d.page_content) for d in docs]

    print(f"총 청크 수: {len(docs)}")
    print(f"평균 크기: {sum(sizes)/len(sizes):.0f}자")
    print(f"최소 크기: {min(sizes)}자")
    print(f"최대 크기: {max(sizes)}자")
    print(f"\n샘플 청크 ({sample_size}개):")

    for i, doc in enumerate(docs[:sample_size]):
        print(f"\n[청크 {i+1}]")
        print(f"크기: {len(doc.page_content)}자")
        print(f"내용: {doc.page_content[:100]}...")
        print(f"메타: {doc.metadata}")
```

## 💡 핵심 포인트
- `RecursiveCharacterTextSplitter`가 대부분 경우에 최적의 선택
- `chunk_overlap`은 청크 간 맥락 유지를 위해 필수 (chunk_size의 10~20%)
- 한국어는 영어보다 토큰 밀도가 높아 chunk_size를 작게 설정
- 메타데이터(source, page)를 항상 보존할 것

## ⚠️ 주의사항
- 청크가 너무 작으면 맥락 부족, 너무 크면 관련 없는 정보 포함
- DirectoryLoader 사용 시 파일 인코딩 오류 처리 필수
