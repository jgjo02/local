## 4. Q&A 예상 질문 대비

### 4.1 기술 질문

```
Q: 왜 Fine-tuning 대신 RAG를 선택했나요?
A:
- 데이터가 자주 업데이트됨
- Fine-tuning은 비용이 높음
- RAG로 새 데이터 즉시 반영 가능
- 소스 추적(출처 표시) 용이

Q: 하이브리드 검색 가중치(0.4/0.6)는 어떻게 결정했나요?
A:
- 여러 조합 실험 (0.3/0.7, 0.5/0.5 등)
- 테스트 쿼리 세트로 평가
- BM25: 정확한 용어 매칭 우선 쿼리
- Dense: 의미 기반 쿼리
- 균형점 0.4/0.6이 전반적으로 우수

Q: 모델 비용은 어느 정도인가요?
A:
- gpt-4o-mini: 1M 입력토큰 $0.15
- 쿼리당 약 2000토큰 → $0.0003 (0.4원)
- 월 1만 쿼리 기준 약 4,000원
```

### 4.2 비즈니스 질문

```
Q: 실제 서비스로 발전시킬 계획이 있나요?
A:

- ETF 추천: 금융투자업 인가 필요

Q: 데이터 품질 관리는 어떻게 하나요?
A:
```

## 5. 발표 연습 가이드

### 5.1 셀프 리뷰

```
발표 녹화 체크리스트:
□ 속도: 분당 약 150-200 단어
□ 명확성: 전문 용어 설명 여부
□ 눈 맞춤: 카메라/청중을 보는가?
□ 데모: 순서가 자연스러운가?
□ 시간: 예상 시간 내 완료?
```

### 5.2 피드백 수집 포인트

```
1. "이 부분이 이해가 안 됐어요" → 설명 개선
2. "데모가 너무 빨랐어요" → 속도 조절
3. "이 기술은 왜 선택했나요?" → 선택 근거 보강
4. "결과가 좋다는 증거가 있나요?" → 지표 추가
```

## 핵심 정리

**좋은 기술 발표의 3요소**:
1. **스토리**: 문제 → 솔루션 → 성과의 흐름
2. **데모**: 百聞不如一見 - 직접 보여주기
3. **자신감**: 질문에 "모른다"도 당당하게

> "좋은 개발자는 코드를 잘 짜고,
> 뛰어난 개발자는 그것을 잘 설명한다."
