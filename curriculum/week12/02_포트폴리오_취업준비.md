## 3. 기술 면접 준비

### 3.1 자주 출제 문제

**RAG 관련**:
```
Q: RAG와 Fine-tuning의 차이점은?
A:
- RAG: 외부 지식 동적 검색, 실시간 업데이트 가능, 비용 낮음
- Fine-tuning: 모델 파라미터 업데이트, 특정 태스크 최적화
- 선택 기준: 지식 업데이트 빈도, 도메인 특화 정도, 비용 고려

Q: 하이브리드 검색의 장점은?
A:
- BM25: 정확한 키워드 매칭, 도메인 용어에 강점
- Dense: 의미적 유사성, 다양한 표현 처리
- 결합: 두 방식의 단점 보완, 전반적으로 우수한 성능
```

**LangGraph 관련**:
```
Q: LangChain과 LangGraph의 차이점은?
A:
- LangChain: 선형 파이프라인 (LCEL)
- LangGraph: 순환 가능한 상태 그래프
- 사용 시: 반복, 조건분기, Human-in-the-Loop 필요 시 LangGraph

Q: MemorySaver vs 일반 대화 이력 관리?
A:
- MemorySaver: 체크포인트 저장, 중단점 재개 가능
- ChatMessageHistory: 단순 메시지 저장
- LangGraph 체크포인트: 전체 상태(메시지+변수) 저장
```

**최적화 관련**:
```
Q: LLM 서비스 비용을 어떻게 줄이나요?
A:
1. 모델 선택: gpt-4o-mini (gpt-4o 대비 ~95% 저렴)
2. 캐싱: 동일 쿼리 재사용
3. 프롬프트 최적화: 불필요한 토큰 제거
4. 배치 처리: 개별 호출 대신 배치
5. 검색 개선: 관련 문서만 컨텍스트에 포함
```
