## 2. RAG 2.0 트렌드

### 2.1 새로운 RAG 패턴

**GraphRAG (Microsoft)**:
```python
# 문서를 지식 그래프로 변환 후 그래프 기반 검색
# 전역 쿼리 (문서 전체 요약) 처리 가능

from graphrag.query.context_builder import LocalSearchMixedContext
# 커뮤니티 요약 + 엔티티 관계 활용
```

**Modular RAG**:
```python
# 검색 → 재순위 → 압축 → 생성을 모듈로 조합
modules = {
    "retriever": HybridRetriever(...),
    "reranker": CohereRerank(...),
    "compressor": LLMCompressor(...),
    "generator": ChatOpenAI(...),
}
```

**Self-RAG 2.0 / CRAG**:
- Speculative RAG: 병렬 검색 후 최적 선택
- Adaptive-RAG: 쿼리 복잡도 자동 감지
