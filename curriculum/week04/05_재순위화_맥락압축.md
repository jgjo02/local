# 5차시: 재순위화 & 맥락 압축

## 학습 목표
- Re-ranking의 원리와 필요성을 이해한다
- Cross-Encoder 기반 재순위화를 적용할 수 있다
- ContextualCompressionRetriever로 검색 결과를 압축할 수 있다

---

## 1. Re-ranking의 필요성

```
1단계 (Bi-Encoder): 빠르지만 정밀도 낮음
  쿼리 → 벡터 변환 → ANN 검색 → 후보 20개

2단계 (Cross-Encoder): 느리지만 정밀도 높음
  (쿼리, 문서1) → 관련성 점수
  (쿼리, 문서2) → 관련성 점수
  ...
  → 상위 4개 선택

결과: 속도 + 정밀도 균형 (2-stage retrieval)
```

---

## 2. Cross-Encoder vs Bi-Encoder

| 항목 | Bi-Encoder | Cross-Encoder |
|------|-----------|---------------|
| 방식 | 각각 인코딩 후 비교 | 쌍으로 함께 인코딩 |
| 속도 | 빠름 (벡터 미리 계산) | 느림 (실시간 쌍 처리) |
| 정확도 | 보통 | 높음 |
| 활용 | 1차 검색 | 2차 재순위화 |

## 3. Cohere Reranker

```python
from langchain_cohere import CohereRerank
from langchain.retrievers import ContextualCompressionRetriever

# Cohere 재순위화 (API 필요)
reranker = CohereRerank(
    model="rerank-multilingual-v3.0",
    top_n=4
)

compression_retriever = ContextualCompressionRetriever(
    base_compressor=reranker,
    base_retriever=vectorstore.as_retriever(search_kwargs={"k": 20})
)

# 1차: 20개 검색 → 2차: Cohere가 4개로 재순위화
docs = compression_retriever.invoke("청약 1순위 조건")
```

## 4. LLM 기반 맥락 압축

### LLMChainExtractor
각 문서에서 관련 부분만 추출:

```python
from langchain.retrievers.document_compressors import LLMChainExtractor

extractor = LLMChainExtractor.from_llm(llm)

compression_retriever = ContextualCompressionRetriever(
    base_compressor=extractor,
    base_retriever=base_retriever
)

# 긴 문서에서 질문 관련 부분만 추출하여 반환
docs = compression_retriever.invoke("청약 점수 계산")
```

### LLMChainFilter
관련 없는 문서 완전 제거:

```python
from langchain.retrievers.document_compressors import LLMChainFilter

_filter = LLMChainFilter.from_llm(llm)

compression_retriever = ContextualCompressionRetriever(
    base_compressor=_filter,
    base_retriever=base_retriever
)
```

### EmbeddingsFilter
임베딩 유사도 기반 빠른 필터링:

```python
from langchain.retrievers.document_compressors import EmbeddingsFilter
from langchain_openai import OpenAIEmbeddings

embeddings_filter = EmbeddingsFilter(
    embeddings=OpenAIEmbeddings(),
    similarity_threshold=0.76
)

compression_retriever = ContextualCompressionRetriever(
    base_compressor=embeddings_filter,
    base_retriever=base_retriever
)
```

## 5. 파이프라인 결합

```python
from langchain.retrievers.document_compressors import DocumentCompressorPipeline
from langchain_text_splitters import CharacterTextSplitter

# 1) 문서 청킹 → 2) 임베딩 필터 → 3) LLM 추출
pipeline_compressor = DocumentCompressorPipeline(
    transformers=[
        CharacterTextSplitter(chunk_size=300, chunk_overlap=0, separator="\n"),
        EmbeddingsFilter(embeddings=OpenAIEmbeddings(), similarity_threshold=0.7),
        LLMChainExtractor.from_llm(llm)
    ]
)

pipeline_retriever = ContextualCompressionRetriever(
    base_compressor=pipeline_compressor,
    base_retriever=vectorstore.as_retriever(search_kwargs={"k": 10})
)
```

---

## 💡 핵심 포인트
- Re-ranking은 2-stage 검색: 빠른 ANN → 정밀한 Cross-Encoder
- ContextualCompressionRetriever로 노이즈 제거 및 정보 압축
- EmbeddingsFilter가 LLM 기반 방법보다 빠르고 저렴함
- 검색 파이프라인: 많이 검색(k=20) → 재순위화 → 상위 4개
