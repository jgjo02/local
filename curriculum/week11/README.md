# Week 11: 멀티모달 RAG

## 주요 학습 내용

이미지, 텍스트, 표를 통합 처리하는 멀티모달 RAG 시스템을 구축합니다.

## 세션 구성

| 차시 | 주제 |
|------|------|
| 1차시 | 멀티모달 AI 개요 & VLM 비교 |
| 2차시 | CLIP 임베딩 & 멀티모달 벡터저장소 |
| 3차시 | 멀티모달 검색 시스템 설계 |
| 4차시 | Vision LLM 활용 (차트/표 분석) |
| 5차시 | IR 보고서 멀티모달 RAG 완성 |

## 학습 목표

- CLIP으로 이미지-텍스트 통합 임베딩 생성
- GPT-4o Vision으로 차트, 표 자동 분석
- 텍스트+이미지 통합 RAG 시스템 구축
- Gradio 멀티모달 UI 구현

## 핵심 아키텍처

```
IR 보고서 (PDF)
    │
    ├── 텍스트 추출 → 텍스트 임베딩 → FAISS
    └── 이미지 추출 → Vision LLM → 캡션 → FAISS
                            │
                    멀티모달 통합 검색
                            │
                    LLM 통합 답변 생성
```
