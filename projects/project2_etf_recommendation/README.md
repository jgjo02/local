# Project 2: ETF 추천 RAG 시스템

## 프로젝트 개요

하이브리드 검색과 LLM을 활용하여 투자자 성향에 맞는 ETF를 추천하는 AI 시스템입니다.

## 시스템 아키텍처

```
┌────────────────────────────────────────────────────────┐
│                  Gradio Web Interface                   │
│  투자자 설문 → ETF 검색 → 추천 결과 → 비교 차트         │
└──────────────────────┬─────────────────────────────────┘
                       │
┌──────────────────────▼─────────────────────────────────┐
│               ETF Recommender Engine                    │
│                                                         │
│  ┌────────────┐    ┌────────────┐    ┌───────────────┐ │
│  │ BM25 Index │    │FAISS Index │    │ Cohere Reranker│ │
│  │ (키워드)   │    │ (의미)     │    │ (재순위화)    │ │
│  └──────┬─────┘    └─────┬──────┘    └───────┬───────┘ │
│         └────────── RRF ─┘               LLM │        │
│                     │                  추천 생성│        │
└─────────────────────┼────────────────────────┘        │
                       │
┌──────────────────────▼─────────────────────────────────┐
│              ETF Data Layer                             │
│  ETF 메타데이터 + 수익률 + 위험 등급 + 테마 정보         │
└────────────────────────────────────────────────────────┘
```

## 핵심 기능

- **하이브리드 검색**: BM25 + 벡터 검색 + RRF 결합
- **투자자 프로파일링**: 5가지 질문으로 위험 성향 파악
- **맞춤 추천**: 성향에 맞는 ETF 5개 추천 + 이유 설명
- **ETF 비교**: 2개 ETF의 상세 비교 분석
- **포트폴리오 제안**: 분산 투자 전략 제안

## 설치 방법

```bash
pip install -r requirements.txt
cp .env.example .env
# .env 파일에 API 키 설정
python app.py
```

## 기술 스택

- LangChain v0.3, LangGraph
- OpenAI GPT-4o-mini, text-embedding-3-small
- FAISS (벡터 검색), rank-bm25 (키워드 검색)
- Gradio 4.x (UI)
- Plotly (차트)

## 법적 고지

이 시스템은 투자 정보를 제공하며, 특정 투자 상품에 대한 투자권유가 아닙니다.
투자 결정은 본인의 판단으로 하시기 바랍니다.
